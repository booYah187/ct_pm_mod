Overlay system: Within resources.bin, a new options directory is created by the DefinitiveEdition.ctp. options/ contains multiple subdirectories, following the format of /optionname/optionnumber/originaldirectory/originalfiles. For example, face 1 in config.txt will use the face.png located in resources.bin at /options/face/1/Extension/face.png instead of the default at /Extension/face.png. Defaults at 0 will use the base assets. Config options set first will prioritize the first assets it finds.
